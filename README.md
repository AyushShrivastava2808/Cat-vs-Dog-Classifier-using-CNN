# 🐱🐶 Cat vs Dog Classifier

## 📌 Project Overview
This project demonstrates the use of a **Convolutional Neural Network (CNN)** to classify images of cats and dogs.  
The model is built using **TensorFlow/Keras** and trained on the popular **Kaggle Dogs vs Cats dataset**.  
It provides both **local** and **Google Colab** notebooks, giving flexibility to run the project on your own machine or directly in the cloud.

---

## 🛠️ Technologies Used
- **Programming Language**: Python  
- **Deep Learning Frameworks**: TensorFlow, Keras  
- **Data Handling**: NumPy, Pandas  
- **Visualization**: Matplotlib  
- **Image Processing**: OpenCV  
- **Machine Learning Utilities**: scikit-learn
